# Onboarding and PR review

## How to use this section
1. Read the reference controller and service in the reference folder.
2. Review the intentionally poor implementation in the review folder.
3. Leave feedback as if you were opening a PR for the review controller.

## Suggested review points
- Extract business logic into a service.
- Avoid `any` in request payloads.
- Add proper validation and error handling.
- Prefer clear, declarative code over imperative loops.
